# 📊 Tokio Master Analytics Pro

Plataforma web de analítica bursátil y gestión de riesgo automatizada, diseñada para traders y analistas cuantitativos. 

Evolucionada desde un prototipo de escritorio tradicional (`Tkinter`) hacia una arquitectura web moderna y escalable.

---

## 🚀 Características Principales
- **Interfaz Web Interactiva:** Desarrollada con **Streamlit** para una experiencia de usuario fluida y responsiva.
- **Gráficos Bursátiles Avanzados:** Visualización de velas interactivas mediante **Plotly**.
- **Motor Financiero:** Procesamiento de datos de mercado en tiempo real utilizando `yfinance`, Pandas y NumPy.
- **Gestión de Riesgo:** Cálculo automatizado de dimensionamiento de posición, capital y distancia de *Stop Loss*.
- **Persistencia de Datos:** Almacenamiento local con **SQLite3** para auditoría del historial de consultas.

---

## 🛠️ Stack Tecnológico
- **Lenguaje:** Python 3.10+
- **Frontend / UI:** Streamlit
- **Visualización:** Plotly
- **Datos y Finanzas:** Pandas, NumPy, yfinance
- **Base de Datos:** SQLite3
